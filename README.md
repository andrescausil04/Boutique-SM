# Boutique S&M — Sandalias & Camisetas Bordadas

Tienda en línea de Boutique S&M: sandalias altas y camisetas bordadas con atención al cliente por WhatsApp e Instagram.

## 🌐 Sitio publicado

[https://andrescausil04.github.io/Boutique-SM/](https://andrescausil04.github.io/Boutique-SM/)

## 🛍️ Funcionalidades

- Catálogo de productos con imágenes reales
- Búsqueda por nombre, marca o categoría
- Filtros por categoría y precio
- Ordenamiento (más populares, precio, nuevos)
- Vista rápida del producto con carrusel de imágenes
- Carrito de compras guardado en el navegador (localStorage)
- Puntuaciones (rating) de productos guardadas localmente
- Pedido coordinado por WhatsApp (total y detalle del carrito)
- Enlaces directos a WhatsApp e Instagram

## 🛠️ Tecnologías

- HTML5
- CSS3
- JavaScript (vanilla)
- Bootstrap 5
- Font Awesome
- GitHub Pages (despliegue)
